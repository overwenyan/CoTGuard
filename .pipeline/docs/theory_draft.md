## 4.1 为什么不能照搬水印文献的保证

水印检测（arXiv:2404.01245 / 2501.02441 / 2411.13868）的 Type I 控制**全部**建立在密钥与采样过程的
密码学耦合上：verifier 用密钥重算伪随机数 `ζ_t = A(w_{1:t-1}, Key)`，据此构造 pivotal statistic
`Y_t = Y(w_t, ζ_t)`，其零分布 `µ0` **不依赖未知的 NTP 分布 `P_t`**。这需要 token 级访问与对采样的
白盒控制。

CoTGuard 的 verifier 只看得到候选轨迹的**文本**，拿不到 `ζ_t`，因此得不到 `Y_t ~ U(0,1)` 这类免费的
精确零分布。

> **红线**：不得声称 CoTGuard 具有密码学式的分布无关保证。该主张一眼可辨为假。

**但框架真正要求的只有一件事**：一个零分布已知、且不含 nuisance parameter 的逐步统计量。至于这个
已知零分布来自密码学还是来自**校准集**，框架并不关心。这为黑盒语义检测器留了门。

## 4.2 共形校准：Type I 控制的诚实来源

设 verifier 持有干净轨迹校准集 `𝒞 = {R^clean_1, …, R^clean_m}`（同任务分布、未注入 trigger）。
把每条干净轨迹的每一步对 trigger pattern `τ` 打分，汇集成校准分数池
`S^clean = {s^clean_1, …, s^clean_m}`（`m` 为池大小）。

对候选轨迹的第 `t` 步，其分数 `s_t` 的**共形 p 值**定义为

```
p_t  =  ( 1 + #{ j : s^clean_j ≥ s_t } ) / ( m + 1 )
```

**引理 1（有限样本 Type I 控制）.** 若在 `H0` 下 `s_t` 与校准分数 `S^clean` 可交换（exchangeable），
则 `p_t` 随机优超于 `U(0,1)`，即对任意 `α ∈ (0,1)`，`P_{H0}(p_t ≤ α) ≤ α`。

*证明思路*：标准共形预测论证。可交换性下 `s_t` 在 `m+1` 个分数中的秩均匀分布于 `{1,…,m+1}`，
`p_t` 即归一化秩。这是有限样本结论，不需要渐近性，也不需要对分数分布做任何参数假设。

> **地基的转换**：从"密码学新鲜随机性"换成"可交换性"。后者对黑盒设定可辩护，代价是**必须真实交付
> 一个干净轨迹校准集**——实验不能省，且校准集必须与候选轨迹同任务分布（分布漂移会破坏可交换性，
> 这是该路线最需要在实验中守住的前提）。

拿到逐步 p 值后，Tr-GoF 的算法第 5–6 步只吃 p 值序列（第 2–4 步的 `ζ_t`/pivot/转 p 值是水印特有的），
因此整套 GoF 机器可以直接接管。

## 4.3 假设

**A1（共形有效性）.** `H0` 下候选轨迹的逐步分数与校准池可交换 ⟹ 引理 1 成立，`p_t` 随机优超 `U(0,1)`。

**A2（跳间几何衰减）.** 每次转述独立地以概率 `ρ ∈ (0,1)` 保留某一步的 trigger 信号。于是 `N` 跳后
携带信号的步比例为

```
ε_N = ε_0 · ρ^N ,        ε_0 ∈ (0,1) 为注入时的初始信号密度
```

**A3（步间弱相关）.** `{p_t}` 满足使稀疏混合渐近适用的 mixing 条件。

**A4（区制参数）.** 沿用 Tr-GoF 的渐近区制：信号稀疏度 `ε_N ≍ n^{-p_N}`，NTP 规则性
`1 - max_w P_{t,w} ≍ n^{-q}`，`q ∈ [0,1)`。

---

## 4.4 主定理：最大可检测跳数

**推导.** 由 A2 与 A4，令 `L := log(1/ρ) > 0`，`c_0 := log(1/ε_0) > 0`：

```
ε_N = ε_0 ρ^N = n^{-p_N}
⟹  -p_N · log n = log ε_0 + N log ρ
⟹  p_N = ( N·L + c_0 ) / log n
```

即**跳数直接线性地推高有效稀疏度指数 `p_N`**——每多一跳，信号在渐近区制下就稀疏一档。

**(i) Tr-GoF 聚合.** 可检测区域为 `q + 2p_N < 1`：

```
2( N·L + c_0 ) / log n  <  1 - q
⟹  N  <  N*(n)  =  [ ((1-q)/2)·log n  -  c_0 ] / L
                =  [ ((1-q)/2)·log n  +  log ε_0 ] / log(1/ρ)
```

**(ii) 求和型聚合（即预印本 Algorithm 4 所属族）.** Tr-GoF 已证该族最优边界仅为 `q + p_N < 1/2`：

```
( N·L + c_0 ) / log n  <  1/2 - q
⟹  N  <  N*_sum(n)  =  [ (1/2 - q)·log n  +  log ε_0 ] / log(1/ρ)
```

**(iii) 差值（原 [存疑] 项，现已核算）.**

```
N* - N*_sum  =  { (1-q)/2  -  (1/2 - q) } · log n / L
             =  { 1/2 - q/2 - 1/2 + q } · log n / L
             =  ( q / 2 ) · log n / log(1/ρ)
```

> ✅ **核算结论：差值系数确为 `q/2`**，digest_theory.md 中标注的 [存疑] 项**成立**。
> 但须补两点限定：(a) `q > 0` 时增益才严格为正，`q = 0`（NTP 接近均匀）时两者重合；
> (b) `N*_sum` 要求 `q < 1/2`，而 `N*` 只要求 `q < 1`——**在 `q ∈ [1/2, 1)` 的区制下求和型聚合
> 完全失效而 Tr-GoF 仍可检测**，这比系数差值是更强的论据。

---

### 定理陈述（论文用）

> **定理（多跳可检测性视界）.** 在 A1–A4 下，设候选推理轨迹含 `n` 步并经历 `N` 次转述。
> 使用共形 p 值 + Tr-GoF 聚合的检测器，存在使 Type I 与 Type II error 同时趋于 0 的检验，
> 当且仅当
> ```
> N  <  N*(n)  =  [ ((1-q)/2)·log n + log ε_0 ] / log(1/ρ)  =  Θ(log n)
> ```
> 若改用求和型聚合，可检测跳数严格收缩为 `N*_sum(n) = N*(n) - (q/2)·log n / log(1/ρ)`；
> 且当 `q ≥ 1/2` 时求和型聚合在任何跳数下均失效。

### 两个可写进 abstract 的结论

1. **推理层来源信号的可检测跳数仅随轨迹长度对数增长**（`N* = Θ(log n)`）。这意味着多智能体系统中的
   来源追踪存在**内在的、可量化的视界**——想多撑一跳，轨迹长度需**指数级**增长。这是一个负面但深刻
   的结果，且是单模型单跳工作（BadChain / ShadowCoT / BadThink）在结构上无法触及的问题。
2. **把聚合从求和换成截断 GoF 严格扩大可检测跳数**，且在 `q ≥ 1/2` 区制下是有无之别。这把"换检测器"
   从工程调参升级为**有理论依据的必要改动**。

## 4.5 承重分析：哪些假设扛得住审稿

| 假设 | 承重 | 可辩护性 | 应对 |
|---|---|---|---|
| **A1 共形有效性** | **最重**——Type I 控制全靠它 | **好**。可交换性远弱于密码学耦合，且是共形预测标准论证 | 必须交付真实干净轨迹校准集；须检验校准集与候选轨迹的分布漂移 |
| **A2 几何衰减** | 重——`N*` 的形状由它决定 | **中**。是一阶建模选择 | **可实测**：跑 N=1..8 量 `ε_N` 看是否几何衰减。把假设变成实验（= S5 的 I3） |
| **A3 步间弱相关** | 中——稀疏混合渐近需要 | **弱，最大软肋** | 见下 |
| **A4 区制参数** | 中——`q` 的可估性 | 中 | `q` 需从数据估计，实验须报告其估计方式与敏感性 |

### A3 是最大的洞，必须正面处理

推理步天然高度依赖：第 `t+1` 步条件于第 `t` 步。水印文献靠哈希的新鲜随机性使 `Y_t` 天然独立，
**我们没有这个便利**。若不处理，定理的渐近基础不成立。

三条应对，建议全部采用：

1. **分块打分**：把轨迹切成若干语义块，块内聚合、块间视作弱相关单元，降低有效依赖强度。
2. **显式写成 α-mixing 条件**并给出所需的混合速率，坦承这是理想化而非可验证前提。
3. **经验佐证**：用干净轨迹实测 p 值序列的自相关函数，报告其衰减，说明 mixing 假设在实践中的合理程度。

> **审稿预期**：会有审稿人指出 A3 无法验证。诚实写法是把定理定位为"在标准弱相关假设下的渐近刻画"，
> 并用经验自相关曲线支撑，而不是假装依赖不存在。

## 4.6 与预印本 Table 4 现象的一致性

预印本观测到 anti-CoT 改写攻击（破坏推理结构）比 post-processing 输出改写伤害大得多
（GPT-4o 上 LDR 从 85.2 掉到 68.4，另一种仅掉到 81.5）。

本框架给出解释：改写降低每跳信号保留概率 `ρ`，而 `N*` 中 `ρ` 出现在**分母的 `log(1/ρ)`**，
`ρ` 略降会显著抬高 `log(1/ρ)` 从而压缩 `N*`；同时求和型聚合（原 Algorithm 4）在信号被稀释时
本就次优，两个效应叠加。

> 这不是事后附会——它给出**可证伪的预测**：若换用 Tr-GoF 聚合，anti-CoT 攻击下的性能下降应当
> 显著小于求和型聚合。**S5 实验必须直接检验这一条**；若不成立，整条理论路线需要重估。
