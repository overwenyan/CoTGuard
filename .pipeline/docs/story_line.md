## 一句话主张

> 语义 CoT trigger 确实把密钥信息写进了推理轨迹，但**基于 trigger 文本相似度的读出
> 方式几乎完全提取不到它**——信号强到一个**不需要任何语义模型的词级 n-gram 分类器**
> 就能取出 3.0–7.4 倍于随机（纯功能词统计也有 1.8–3.6 倍），且该签名**在 10 跳语义改写
> （含对抗性规避）后基本不衰减**，在部署现实条件下同样成立。问题从来不在于需要更强的
> 模型，而在于**读出范式选错了**。

⚠️ **主张已于 EXP-B1 后修订**：原主张"我们提出学习式 embedding 读出"已作废——
四个 run 的公平对比里该读出**两平两负、一次没赢过**朴素 TF-IDF。按预先写定的预案
改主张而非调参，详见 `experiment_ledger.md` EXP-B1 v2。

## 证据链（每一环都有实验编号，全部可复现）

| 环节 | 发现 | 证据 |
|---|---|---|
| 1 | 预印本检测器在**控制长度混淆后等同随机** | EXP-R0：length-matched AUROC 0.543；只数步数即 0.879 |
| 2 | trigger 使轨迹步数 7.38 → 14.38，信号大量由长度承载 | EXP-R0 |
| 3 | 用 trigger 文本做归因，top-1 **停在随机水平** | EXP-R1：0.127/0.127/0.137 vs 随机 0.125 |
| 4 | 把 pattern 相似度 max 从 0.897 压到 0.329，归因**仍不改善** | EXP-R1（排除"密钥空间设计"解释） |
| 5 | **但密钥信息确实在轨迹里**：学习式读出达 3.8× 随机 | EXP-R1b：logistic top-1 0.475（GSM8K, Tulu-3-8B） |
| 6 | 该能力**不依赖单一 embedding** | EXP-R1c：mpnet 0.4475 / gte-base 0.4242（5 seeds） |
| 7 | 信号是 **per-key 特异签名**，非通用语义映射 | EXP-R1d：留出密钥泛化失败，**三档正则化 + 容量对照**排除欠拟合 |
| 8 | **跨模型成立且更强** | EXP-R2 v2：Qwen3-14B 达 0.53–0.61（＞Tulu 的 0.36–0.48） |
| 9 | **10 跳语义改写后基本不衰减** | S12：guard_lexicon .4306→.4111，paraphrase .4306→.3903 |
| 10 | **对抗性规避无效** | guard_lexicon 未比良性 paraphrase 更能破坏签名 |
| 11 | **部署现实条件下同样成立** | EXP-R4：train-on-hop0 → test-on-hopN 与同跳重训无显著差异（t=−1.18） |
| 12 | 跨数据集复现，但**效应量域依赖** | EXP-M1：MATH-500 上 2.0–2.2×（GSM8K 2.9–3.8×），已排除长度解释 |
| 13 | 域依赖**不是形式化程度**造成的 | EXP-F1：FOLIO（纯一阶逻辑，形式化程度不低于 MATH）达 3.40×，贴近 GSM8K 而非 MATH——**排除性证据** |
| 14 | 域依赖**主要是 embedding 的伪影** | EXP-B1：MATH 相对 GSM8K 的保留率 TF-IDF 68% vs embedding 52%——**差分证据** |
| 15 | 签名相当程度上是**纯写作习惯**，非内容语义 | EXP-B1：仅功能词+标点频率（零内容）达 1.8–3.6×——第 7 环的**正面独立证据** |
| 16 | **不需要语义模型**：最朴素读出即达上界 | EXP-B1：TF-IDF 3.0–7.4×，学习式 embedding 读出两平两负未曾胜出 |

⚠️ **第 9/11 环待重测**：这两环当初用的是学习式 embedding 读出，而主方法已改为 TF-IDF
读出。不重测就等于用一个已被降级的读出器支撑鲁棒性主张。EXP-B2（作业 20040031）
正在用两种读出器各跑一遍，以便报告"鲁棒性结论是否依赖读出器选择"。**在结果出来前，
第 9/11 环只对 embedding 读出成立。**

**结构优势**：第 4 环与第 7 环是**排除性证据**（分别排除"密钥空间设计不当"与"模型容量
不足"），第 11 环是**自我设障后通过**（主动补测部署现实场景）。这种结构比单点正面结果
更难被推翻。

## 按竞品模板的四个写作动作

### 动作一：开场锚定真实部署 + 命名资产

推理轨迹在多智能体系统中被中继、被复用；轨迹数据本身成本高昂（ActHook 用 $100/条论证过）。
资产 = **owner 的 k-引导推理轨迹**。

### 动作二：两层 gap（写成失效模式，不写"没人做过"）

**第一层（整类方法机理上不适用）**：行为层水印（AgentMark / SeqWM / Agent Guide / ActHook）
依赖"从有限候选集中选离散动作"——密钥由构造可分离。CoT 推理**没有候选集、没有可保的
每步分布、载体是连续自然语言**，行为层赖以成立的基质不存在。

**第二层（同类工作在什么条件下会碎）**：引用它们自己的数字——AgentMark 的 Bit Recovery
在语义改写下塌到 **16.84%** 且 Limitations 自认 paraphrasing 是失效模式；SeqWM 把
"semantic paraphrase-style trajectory edits" 列为 future work。收口：
**语义改写正是推理轨迹在 agent 间中继时所做的事。**

### 动作三：方法（**已改**：从"提出新读出器"改为"读出范式的对照研究"）

中心论点不再是某个具体读出器，而是**范式选择**：不要去测"轨迹是否像 trigger 文本"
（判别式假设错误），而要**从 owner 自己生成的参考轨迹里学每个密钥的判别边界**。

关键实证：在这个正确范式下，**连最朴素的读出器都够用**——词级 TF-IDF + SVD 取到
3.0–7.4× 随机，只用功能词与标点（零内容信息）也有 1.8–3.6×，而 trigger 文本相似度
只有 1.7–3.4×，在每个数据集上都被 TF-IDF 大幅超过。

**把"方法简单"写成卖点而非辩解**：检测器免 GPU、特征可解释、可在 CPU 上对海量轨迹
批量筛查——对取证/水印场景这是实打实的优点。审稿人最爱问的"是不是过度设计"被提前答掉。

配套两个必需组件（均由实验逼出，非工程细节）：
- **per-pattern 标准化**（EXP-005）：不同 trigger pattern 对文本有异质固有亲和度
  （sd=0.0299），不消掉则校准彻底失效（KS 0.44 → 0.086）
- **length-matched 评估**（EXP-R0）：不控制则 AUROC 被步数平凡驱动

### 动作四：轻量理论（服务设计选择，不承担新颖性）

参照 PolicyGuard（同组，ICML 2026，理论约一页且部分借用）：给一条说明"为何文本相似度
读出必然次优"的命题即可，不追求渐近最优性。

## 主表规划（四张，均已有数据）

1. **utility 影响**（EXP-U1，已完成）：**不是"不掉点"而是模型相关**——
   Tulu-3-8B（clean 0.620）上 trigger 提升至 0.71–0.81；Qwen3-14B（clean 0.910）上
   轻微下降至 0.81–0.90。多跳改写不损害正确率（各跳 0.752–0.767）。
2. **归因能力对比**（EXP-R1/R1b/R2/M1）：trigger-文本相似度 vs 学习式读出 ×
   三种密钥空间 × 两个生成模型 × 两个数据集。
3. **多跳改写鲁棒性**（S12 + EXP-R4）：0–10 跳 × 两种改写风格 × 两种评估协议
   （同跳重训 / 部署现实的跨跳迁移）。
4. **校准有效性**（EXP-005）：raw / zscore / rank 的 KS 与尾部——**三篇竞品都没有这张表**。

## 必须如实写明的局限

1. **效应量域依赖**：MATH-500 上仅 2.0–2.2× 随机（GSM8K 2.9–3.8×，FOLIO 3.40×）。
   已排除**长度**解释（MATH 轨迹反而更长）与**形式化程度**解释（EXP-F1：FOLIO 形式化
   程度不低于 MATH，效应量却贴近 GSM8K）。EXP-B1 进一步给出**差分证据**：MATH 上
   embedding 退化远大于 TF-IDF（保留率 52% vs 68%），指向"记号密度干扰语义编码器"。
   但**仍不可写成确证机制**——未做记号消融（把 LaTeX 替换为占位符后重测），
   只能写"与该假说一致且被差分对比支持"。
2. **utility 在强模型上有代价**，不能沿用竞品的 "utility preserved" 式无条件主张。
3. **无法零样本泛化到未见密钥**（EXP-R1d），归因需要 per-key 参考数据。owner 持钥
   本就能生成，属可接受的作用域限定，但须写明。
4. **对抗攻击强度有限**：目前只测了单项 guard_lexicon，已证无效；更强的叠加压力版本
   （Guard-Lexicon + Do-Not-Mention + Monitor-Aware）尚未测。**在测过之前，
   不应宣称"对抗鲁棒"，只能说"对该类改写鲁棒"。**
5. **外推禁令**：10 跳线性外推得出的"133–175 跳才降到随机"**不得写入论文**，
   外推 13–17 倍无依据。
