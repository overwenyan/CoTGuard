## 中心机制（EXP-C3，2026-09-10 得到；这是目前为止最像"一个发现"的东西）

> 给 agent 的 CoT 注入一条密钥条件化的指令，会在轨迹里留下**两条来源不同、性质不同的
> 指纹通道**：
>
> - **C1 词法/指令通道**——trigger 里"要求怎么写"的部分（"restate the target"）被模型
>   照做，用词**字面残留**在轨迹里。它**随指令遵循能力增强**（判别 n-gram 与密钥文本
>   重叠：Qwen3-14B 0.771 ≫ Tulu-3-8B 0.312），也**能被词汇擦洗移除**。
> - **C2 特异文体通道**——trigger 里"扮演谁"的部分（"chess coach reviewing a game"）
>   不留任何字面痕迹，只把模型的功能词/标点习惯推进一个**与该 prompt 绑定的任意盆地**。
>   它与密钥语义**无关**（判别功能词与密钥文本重叠恒定 0.11–0.16，四个 run），**擦不掉**。

**为什么这是个发现而不是一句描述**：它把四个原本各自独立、当时只能各自记一笔的观察
统一成一件事——

| 原观察 | 两通道解释 |
|---|---|
| 把密钥语义拉开（相似度 0.897→0.329）归因**毫无改善** | C2 是任意映射，语义距离本就无关 |
| 学过若干密钥后**无法零样本外推**到新密钥 | C2 是任意映射，没有可外推的规律 |
| adaptive 攻击掉 43.5% 后**平台化**在 1.6–1.9× 而非继续衰减 | C1 被移除，**C2 就是那个地板** |
| 纯功能词特征（零内容）就有 1.8–3.6× | 那正是在直接测 C2 |

**可证伪预测（EXP-C4，作业 20040052 在跑）**：把 trigger 拆成 `persona_only` 与
`anchor_only` 两个空间后施加同一攻击——anchor_only 应当起点更高但**塌陷**，
persona_only 应当起点更低但**基本不动**。**若两者衰减幅度无差异，本机制被证伪。**

## 一句话主张（面向读者的表述）

> 给 agent 的 CoT 注入密钥条件化指令留下的指纹，**不是语义的而是文体的**——测轨迹与
> trigger 文本的相似度几乎等于随机，而一个不需要任何语义模型的词级 n-gram 读出就能取到
> 3.0–7.4 倍于随机，连纯功能词与标点统计（零内容信息）都有 1.8–3.6 倍。该指纹在
> **10 跳中继改写后基本不衰减**；monitor-aware 叠加攻击能削掉其中可擦洗的那一条通道，
> 但**消不干净，且攻击者要为此付出 8.3 个百分点的任务正确率**。

**三条给"任何想做这件事的人"的结论**（不依赖本文方法，可独立引用）：
- **检测容易但会被长度平凡驱动**：不做 length matching，AUROC 0.879 是假象（0.543 才是真的）
- **detection ≠ attribution**：能判断"用了某个 trigger"，不等于能判断"用的是哪个密钥"
- **指纹是文体而非语义**：所以语义匹配类读出注定次优，而廉价词法读出就够

## 证据链（每一环都有实验编号，全部可复现）

| 环节 | 发现 | 证据 |
|---|---|---|
| 1 | 语义相似度检测在**控制长度混淆后等同随机** | EXP-R0：length-matched AUROC 0.543；只数步数即 0.879 |
| 2 | trigger 使轨迹步数 7.38 → 14.38，信号大量由长度承载 | EXP-R0 |
| 3 | 用 trigger 文本做归因，top-1 **停在随机水平** | EXP-R1：0.127/0.127/0.137 vs 随机 0.125 |
| 4 | 把 pattern 相似度 max 从 0.897 压到 0.329，归因**仍不改善** | EXP-R1（排除"密钥空间设计"解释） |
| 5 | **但密钥信息确实在轨迹里**：学习式读出达 3.8× 随机 | EXP-R1b：logistic top-1 0.475（GSM8K, Tulu-3-8B） |
| 6 | 该能力**不依赖单一 embedding** | EXP-R1c：mpnet 0.4475 / gte-base 0.4242（5 seeds） |
| 7 | 信号是 **per-key 特异签名**，非通用语义映射 | EXP-R1d：留出密钥泛化失败，**三档正则化 + 容量对照**排除欠拟合 |
| 8 | **跨模型成立且更强** | EXP-R2 v2：Qwen3-14B 达 0.53–0.61（＞Tulu 的 0.36–0.48） |
| 9 | **10 跳语义改写后基本不衰减** | S12：guard_lexicon .4306→.4111，paraphrase .4306→.3903 |
| 10 | **对抗性规避无效** | guard_lexicon 未比良性 paraphrase 更能破坏签名 |
| 11 | **部署现实条件下同样成立** | EXP-R4：train-on-hop0 → test-on-hopN 与同跳重训无显著差异（t=−1.18） |
| 12 | 跨数据集复现，但**效应量域依赖** | EXP-M1：MATH-500 上 2.0–2.2×（GSM8K 2.9–3.8×），已排除长度解释 |
| 13 | 域依赖**不是形式化程度**造成的 | EXP-F1：FOLIO（纯一阶逻辑，形式化程度不低于 MATH）达 3.40×，贴近 GSM8K 而非 MATH——**排除性证据** |
| 14 | 域依赖**主要是 embedding 的伪影** | EXP-B1：MATH 相对 GSM8K 的保留率 TF-IDF 68% vs embedding 52%——**差分证据** |
| 15 | 签名相当程度上是**纯写作习惯**，非内容语义 | EXP-B1：仅功能词+标点频率（零内容）达 1.8–3.6×——第 7 环的**正面独立证据** |
| 16 | **不需要语义模型**：最朴素读出即达上界 | EXP-B1：TF-IDF 3.0–7.4×，学习式 embedding 读出两平两负未曾胜出 |

✅ **第 9/11 环已用新读出器重测通过**（EXP-B2）：TF-IDF 读出下 10 跳后仍保留 88–90%
（hop10 = 3.64× 随机，高于 embedding 的 3.19×），跨跳迁移与同跳重训在所有跳上基本相同。
两种读出器在 adaptive 攻击下给出**同一形状**（首跳跌 37–39% 后平台化），说明"平台"
不是某个读出器的伪影。但形状一致**不等于**两通道假说被确认——判决在 EXP-C4。

**结构优势**：第 4 环与第 7 环是**排除性证据**（分别排除"密钥空间设计不当"与"模型容量
不足"），第 11 环是**自我设障后通过**（主动补测部署现实场景）。这种结构比单点正面结果
更难被推翻。

## 尚未回答、且值得回答的问题

用户 2026-09-10 指示："我们先要做出有意义的自然的工作，可以后面再管审稿人。"
下列问题按**这个现象本身值不值得搞清楚**排序，而非按补齐门槛排序。

1. **两通道假说成不成立** —— EXP-C4 在跑。这是当前唯一一个能被证伪的机制主张。
2. **C2 的容量上限是多少** —— 所有实验都固定 K=8。K=32/64 时 C2 还剩多少？
   这决定这套东西有没有实用价值，也决定"任意盆地"是否真的够多。
3. **同一密钥的改写版本会不会产生同一指纹** —— 若 C2 真是与 prompt 字面绑定的任意盆地，
   那么 k 的一个同义改写应当产生**不同**指纹。这是对"特异 vs 语义"最直接的判决实验，
   比现有任何一条证据都干净，**目前还没做**。
4. **C2 到底是什么** —— 现在只知道"判别性功能词与密钥文本无关"。是句长节律？
   连接词偏好？步骤起始方式？这一层还没打开。
5. **零 trigger 的对照** —— 若把 8 组 clean 轨迹按任意方式分组，归因应当在随机水平。
   这个 null control 一直没跑过，属于必须补的自查。

## 写作动作（**次要**：先有内容再谈怎么讲）

### 动作一：开场锚定真实部署 + 命名资产

推理轨迹在多智能体系统中被中继、被复用；轨迹数据本身成本高昂（ActHook 用 $100/条论证过）。
资产 = **owner 的 k-引导推理轨迹**。

### 动作二：两层 gap（写成失效模式，不写"没人做过"）

**第一层（整类方法机理上不适用）**：行为层水印（AgentMark / SeqWM / Agent Guide / ActHook）
依赖"从有限候选集中选离散动作"——密钥由构造可分离。CoT 推理**没有候选集、没有可保的
每步分布、载体是连续自然语言**，行为层赖以成立的基质不存在。

**第二层（同类工作在什么条件下会碎）**：引用它们自己的数字——AgentMark 的 Bit Recovery
在语义改写下塌到 **16.84%** 且 Limitations 自认 paraphrasing 是失效模式；SeqWM 把
"semantic paraphrase-style trajectory edits" 列为 future work。收口：
**语义改写正是推理轨迹在 agent 间中继时所做的事。**

### 动作三：方法（一个中心 trick：**把溯源当文体归属问题，而不是语义匹配问题**）

中心论点是**范式选择**。任何人拿到这个问题的第一反应都是"测轨迹像不像 trigger 文本"
——这是**语义匹配范式**，而它在四个数据集上都只有 1.7–3.4×，几乎贴着长度基线。
本文主张换成**文体归属范式**：从 owner 自己生成的参考轨迹里学每个密钥的判别边界，
用作者归属文献里那套廉价词法/文体特征。

这个 trick 有机制解释、且被实验反过来印证：
- 指纹是文体的 → 纯功能词+标点（**零内容信息**）就有 1.8–3.6×
- 指纹不是语义的 → 换更强的语义 embedding **没有增益**（两平两负）
- 所以最终检测器**免 GPU、特征可解释、可在 CPU 上对海量轨迹批量筛查**

**"方法简单"是卖点不是辩解**：取证/溯源场景要的就是能大规模廉价跑的筛查器；
而且审稿人最爱问的"是不是过度设计"被提前答死。

配套两个必需组件（均由实验逼出，非工程细节）：
- **per-pattern 标准化**（EXP-005）：不同 trigger pattern 对文本有异质固有亲和度
  （sd=0.0299），不消掉则校准彻底失效（KS 0.44 → 0.086）
- **length-matched 评估**（EXP-R0）：不控制则 AUROC 被步数平凡驱动

### 动作四：轻量理论（服务设计选择，不承担新颖性）

参照 PolicyGuard（同组，ICML 2026，理论约一页且部分借用）：给一条说明"为何文本相似度
读出必然次优"的命题即可，不追求渐近最优性。

## 主表规划（四张，均已有数据）

1. **utility 影响**（EXP-U1，已完成）：**不是"不掉点"而是模型相关**——

4. **校准有效性**（EXP-005）：raw / zscore / rank 的 KS 与尾部——**三篇竞品都没有这张表**。

## 必须如实写明的局限

1. **效应量域依赖**：MATH-500 上仅 2.0–2.2× 随机（GSM8K 2.9–3.8×，FOLIO 3.40×）。
   已排除**长度**解释（MATH 轨迹反而更长）与**形式化程度**解释（EXP-F1：FOLIO 形式化
   程度不低于 MATH，效应量却贴近 GSM8K）。EXP-B1 进一步给出**差分证据**：MATH 上
   embedding 退化远大于 TF-IDF（保留率 52% vs 68%），指向"记号密度干扰语义编码器"。
   但**仍不可写成确证机制**——未做记号消融（把 LaTeX 替换为占位符后重测），
   只能写"与该假说一致且被差分对比支持"。
2. **utility 在强模型上有代价**，不能沿用竞品的 "utility preserved" 式无条件主张。
3. **无法零样本泛化到未见密钥**（EXP-R1d），归因需要 per-key 参考数据。owner 持钥
   本就能生成，属可接受的作用域限定，但须写明。
4. **对抗攻击强度有限**：目前只测了单项 guard_lexicon，已证无效；更强的叠加压力版本
   （Guard-Lexicon + Do-Not-Mention + Monitor-Aware）尚未测。**在测过之前，
   不应宣称"对抗鲁棒"，只能说"对该类改写鲁棒"。**
5. **外推禁令**：10 跳线性外推得出的"133–175 跳才降到随机"**不得写入论文**，
   外推 13–17 倍无依据。

| run | trigger_sim | tfidf_word | embed_meanstd | 判定 |
|---|---|---|---|---|
| GSM8K | 2.23× | **4.39×** | 4.14× | p=0.317 平 |
| Qwen3-14B | 3.44× | **7.44×** | 6.78× | p=0.0042 TF-IDF 胜 |

那么"上更强的语义编码器"本就不该有增益——**实验结果与机制解释相互印证**，
这比单纯报告"TF-IDF 够用"有力得多。

两项附带发现已并入证据链：
- **域依赖主要是 embedding 伪影**：MATH 相对 GSM8K 的保留率，TF-IDF 68% vs embedding 52%
- **签名相当程度是纯写作习惯**：`stylometry_strict`（仅功能词+标点，零内容）达 1.8–3.6×
