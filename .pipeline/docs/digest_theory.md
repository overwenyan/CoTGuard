## 1. A Statistical Framework of Watermarks (Li, Ruan, Wang, Long, Su; arXiv:2404.01245)

### 核心方法

把水印检测严格形式化为假设检验：

- **H0**：`w_{1:n}` 由人类撰写；**H1**：由带水印 LLM 生成。
- **密钥角色**：secret key 经哈希函数 `ζ_t = A(w_{1:t-1}, Key)` 产生伪随机数；带水印模型按 `w_t = S(P_t, ζ_t)`
  解码（`P_t` 为 NTP 分布，verifier 不可知）。
- **两条 Working Hypothesis**：
  - WH 2.1（伪随机性可靠）：`ζ_t` i.i.d. 且与前文 token 独立——纯密码学论证。
  - WH 2.2（人类随机性）：H0 下 `w_t` 与 `ζ_t` 条件独立，因为人类不掌握密钥。
- **Pivotal statistic**：`Y_t = Y(w_t, ζ_t)`，要求其零分布 `µ0` **不依赖未知的 `P_t`**。这正是在 NTP 分布
  未知且逐 token 变化的情况下仍能精确控制 Type I error 的关键。检验问题被约化为
  `H0: Y_t ~ µ0 i.i.d.` vs `H1: Y_t ~ µ_{1,P_t}`。
- **检验规则**：`T_h = 1{ Σ_t h(Y_t) ≥ γ_{n,α} }`，阈值
  `γ̂_{n,α} = n·E_0 h(Y) + Φ^{-1}(1-α)·sqrt(n·Var_0(h(Y)))`。注意 `P_t` 完全不出现在规则中。
- **Type II 分析**：Theorem 2.1 用大偏差理论给出
  `limsup_n P_{H1}(T_h = 0)^{1/n} ≤ e^{-R_P(h)}`，其中
  `R_P(h) = - inf_{θ≥0} sup_{P∈𝒫} { θ E_0 h(Y) + log φ_{P,h}(θ) }`，`φ_{P,h}(θ) = E_{1,P} e^{-θh(Y)}`。
  这是 **class-dependent efficiency rate**，用分布类 `𝒫` 处理"NTP 未知且变化"的难题。
- **最优性**：寻找最优 score function 归结为 minimax program
  `min_h max_{P∈𝒫} L(h,P)`，`L(h,P) = E_0 h(Y) + log E_{1,P} e^{-h(Y)}`。
  作者据此证明 Aaronson 的 Gumbel-max 检测规则**次优**，并给出闭式最优规则。

### 局限性

- 整套保证的地基是**密钥与采样过程的耦合**：verifier 必须能重算 `ζ_t`，这要求 token 级访问 + 已知哈希
  构造 + 对采样的白盒控制（logit 偏置 / Gumbel-max / inverse transform）。
- i.i.d. 假设（WH 2.1）由密码学"新鲜随机性"支撑，是该框架能成立的隐形支柱。
- pivot 的构造是 case-by-case 的手艺活，作者自陈"没有通用配方"。

### 可突破点（对 CoTGuard）

**可迁移的是"pivot 思想"本身，不是 Gumbel-max/inverse-transform 的具体构造。** 框架真正要求的只有一件事：
一个零分布已知、且不含讨厌参数（nuisance parameter）的逐步统计量。至于这个已知零分布从密码学来还是从
**校准集**来，框架并不关心。这为黑盒语义检测器留了门。

## 2. Data Misappropriation Hypothesis Testing (arXiv:2501.02441)

### 核心方法

问题与 CoTGuard **结构同构，只低一层**：判定嫌疑模型是否用了受害模型生成的数据来训练。

- **H0**：`ω_{1:n}` 由无数据挪用的 LLM 生成；**H1**：由有数据挪用的 LLM 生成。
- 沿用 2404.01245 的密钥/pivot/求和检验骨架，但引入两个新设定：
  - **Complete inheritance**（Def. 1）：嫌疑模型继承相同的 `A` 与 `S`。此时
    `H0: ω_t|ζ_t ~ P_t` vs `H1: ω_t|ζ_t ~ S(P_t, ζ_t)`。
  - **Partial inheritance**（Def. 2）：**这是对我们最有价值的构造。**
    `H1: TV_{·|ζ_t}( ω_t, S(P_t,ζ_t) ) ≤ 1 - θ`
    即：嫌疑分布落在真实带水印分布周围的一个 **TV 球**内，`θ` 量化"继承强度"。作者明确说明动机是
    "嫌疑模型无法把语义信号与水印模式解耦，所以必然连带学到水印"，且 `θ` 允许取遍 `(0,1)` 全区间。
- **Theorem 3**：complete inheritance 下 **H0 时 `Y_t ~ U(0,1)`** —— 均匀零分布，即标准 p 值。
- **Theorem 1/2**：把固定 Type I error（以及 Type I+II 之和）的检验同样化为 minimax program，给出
  `R_{P,Q}(h)` 形式的指数率；**Theorem 5** 证明所提检验在 `Ψ_α`（Type I ≤ α 的全体检验）中渐近最优。

### 局限性

- 仍然需要密钥与 `A`（"仅受害者与检测者知晓"），因此仍是 token 级 + 白盒采样的设定。
- Partial inheritance 中"同一区域 `A_i` 内 `ω|ζ` 分布相同"是为解析方便所加的简化假设（作者承认可放松）。
- `θ` 不能太小，否则两分布不可分——这给出了**可检测性的内在下界**。

### 可突破点（对 CoTGuard）

**Partial inheritance 的 TV 球正是多跳转述的正确数学形状。** 每经过一次 agent 转述，候选轨迹分布就从
"我方 trigger 引导的分布"漂开一点；把漂移量写成随跳数增长的 TV 半径 `1 - θ_N`，即可自然地把"跳数"接入
一个已被审稿人接受过的理论骨架。且 `θ` 有下界这一点，直接预示"存在最大可检测跳数"。

## 3. Tr-GoF：Robust Detection under Human Edits (arXiv:2411.13868)

### 核心方法

**这是对本项目杀伤力最大、同时也最有用的一篇。**

- **编辑的混合模型**：由于伪随机性与真随机不可区分，每个 token 要么贡献水印信号、要么在被编辑后沦为噪声。
  于是把编辑后的文本建模为**稀疏混合**：以概率 `ε_n` 携带信号，否则为噪声。
- **渐近区制**：`ε_n ≍ n^{-p}`（信号稀疏度），`1 - max_w P_{t,w} ≍ n^{-q}`（NTP 规则性）。`p`、`q` 越大越难检测。
- **相变边界**：最优可检测区域的边界是 **`q + 2p = 1`**。`q+2p > 1` 时任何检验都无法让 Type I、II 同时趋零；
  `q+2p < 1` 时似然比检验可以做到。
- **对求和型规则的判决**：作者**证明** sum-based 检测规则（即 `Σ_t h(Y_t)` 这一族，含 2404.01245、Aaronson 等）
  **一般达不到 `q+2p=1`**，其最好可能边界只有 **`q + p = 1/2`**。原因是可加统计量对编辑引入的噪声缺乏适应性
  ——信号被稀释后，求和把少数强信号步淹没在多数噪声步里。
- **Tr-GoF 的替代方案**：不再求和，而是比较 p 值的**经验 CDF** `F_n` 与均匀零分布 `F_0(r)=r` 之间的
  φ_s-散度偏离：
  `S_n^+(s) = sup_{r ∈ [p_+, 1)} K_s^+( F_n(r), F_0(r) )`
  其中 `K_s^+` 是 `Ks`（Ber(u) 与 Ber(v) 间的 φ_s-散度）的截断版（仅在 `0<v<u<1` 取值，否则为 0），
  `p_+` 是对 r 域的截断（滤掉极端小 p 值以保稳定）。属于 Higher-Criticism 家族。
- **自适应最优**：Tr-GoF 达到 `q+2p=1` 边界且**无需知道 `ε_n` 或 `∆`**，也无调参；在 dense 区制下同时取得
  2404.01245 框架下最高的 class-dependent efficiency。

### 局限性

- 最优性证明针对 Gumbel-max 水印展开，推广到任意 pivot 需重做。
- 仍建立在 `Y_t` 独立同分布的前提上。
- 稀疏混合的渐近区制（`n → ∞`）对短文本的有限样本行为指导有限。

### 可突破点（对 CoTGuard）

两点，都很关键：

1. **CoTGuard 的 Algorithm 4 正是逐步求和相似度分数，属于被证明次优的 sum-based 家族。** 这既解释了预印本
   Table 4 中"anti-CoT 改写攻击伤害最大"的现象，也给出了有原则的替代方案。这不是"我们换了个聚合函数"，
   而是"文献已证明原聚合方式次优，我们换到最优的那一族"。
2. **Tr-GoF 的第 5-6 步只吃 p 值序列。** 算法框第 2-4 步（算 `ζ_t`、算 pivot、转 p 值）是水印特有的，但一旦
   拿到合法的逐步 p 值，后面的 GoF 机器与水印再无关系。**这意味着只要我们能用任何合法手段造出逐步 p 值，
   整套 Tr-GoF 机器可以直接搬过来。**

## 4. 结论：CoTGuard 能真正证明的定理是什么

### 4.1 硬阻塞：pivot 从哪来

三篇论文的 Type I 控制全部源自**密钥与采样过程的密码学耦合**。CoTGuard 是黑盒 API + 语义相似度，
**没有**这样的耦合，因此 `Y_t ~ U(0,1)` 这类"免费的精确零分布"拿不到。若强行声称有，审稿人一眼看穿。

**诚实的替代：共形校准（conformal calibration）。** 保留一份**未注入 trigger 的干净推理轨迹校准集**
`{R^{clean}_1, ..., R^{clean}_m}`。对候选轨迹的第 t 步，其相似度分数 `s_t` 相对校准集的经验 p 值为

```
p_t = ( 1 + #{ j : s^{clean}_j ≥ s_t } ) / ( m + 1 )
```

在**可交换性（exchangeability）**假设下，这一 p 值在 H0 下随机优超于 `U(0,1)`，从而给出**有限样本**的
Type I 控制。这把地基从"密码学"换成"可交换性"——后者对黑盒设定是可辩护的，且是共形预测的标准论证。
拿到 `p_t` 后，第 3 节第 2 点说明 Tr-GoF 可直接接管。

### 4.2 建议的定理形状（多跳可检测性）

**设定.** 候选推理轨迹经 `N` 次 agent 间转述后被观测，含 `n` 个推理步。检测器按 4.1 计算逐步 p 值，
再用 Tr-GoF 聚合。

**假设 A1（共形有效性）.** 干净轨迹的逐步分数与校准集可交换 ⟹ H0 下 `p_t` 随机优超 `U(0,1)`。

**假设 A2（跳间衰减）.** 每次转述独立地以概率 `ρ ∈ (0,1)` 保留某一步的 trigger 信号，则 `N` 跳后
携带信号的步比例为 `ε_N = ε_0 ρ^N`。

**假设 A3（步间弱相关）.** `{p_t}` 满足某种 mixing 条件，使稀疏混合渐近适用。

**定理（最大可检测跳数）.** 在 A1–A3 下，写 `ε_N ≍ n^{-p_N}`，则 `p_N = (N log(1/ρ) - log ε_0)/log n`。
由 Tr-GoF 的相变边界 `q + 2p_N < 1`，可检测当且仅当

```
N  <  N*(n)  =  [ ((1-q)/2)·log n  +  log ε_0 ] / log(1/ρ)
```

而若沿用 CoTGuard 现有的**求和型**聚合，边界退化为 `q + p_N < 1/2`，给出严格更小的

```
N*_sum(n)  =  [ (1/2 - q)·log n  +  log ε_0 ] / log(1/ρ)   <   N*(n)
```

**两个可写进 abstract 的结论：**

1. **推理层来源信号的可检测跳数仅随轨迹长度对数增长**（`N* = Θ(log n)`）——多智能体系统中的来源追踪
   存在内在的、可量化的视界。这是一个负面但深刻的结果，且是 BadChain/ShadowCoT（单模型单跳）在结构上
   无法触及的问题。
2. **把聚合从求和换成截断 GoF，严格扩大了可检测跳数**，`N* - N*_sum = (q/2)·log n / log(1/ρ) > 0`
   **[存疑：该差值的确切系数需按两条边界重新代数推导，此处为按 `q+2p=1` 与 `q+p=1/2` 直接相减所得，
   投稿前须核算]**。这让"换检测器"从工程调参升级为有理论依据的必要改动。

### 4.3 哪些假设在真正承重，是否扛得住审稿

| 假设 | 承重程度 | 可辩护性 |
|---|---|---|
| A1 共形有效性 | **最重**——Type I 控制全靠它 | **好**。可交换性比密码学耦合弱得多，且是标准论证。但需要真实的干净轨迹校准集，实验必须交付 |
| A2 几何衰减 `ε_N = ε_0 ρ^N` | 重——`N*` 的形状由它决定 | **中**。是一阶建模选择，但**可实测**：跑 N=1..8 跳量出 `ε_N` 看是否几何衰减。把假设变成实验，同时补上"实验不真实"的短板 |
| A3 步间弱相关 | 中——稀疏混合渐近需要 | **弱，是最大软肋**。推理步高度依赖（第 t+1 步条件于第 t 步），水印文献靠哈希新鲜随机性天然去相关，我们没有。建议：分块打分 + 显式写成 α-mixing 条件，并坦承这是理想化，用经验校准曲线佐证 |

**给写作的一句话建议**：不要试图把 CoTGuard 包装成"有密码学保证的水印"——那是假的，且一眼可辨。
应当明确定位为**共形有效（conformally valid）的来源检测**，把诚实的 Type I 控制 + 可实测的跳数衰减律
作为卖点。这比一个站不住的强保证更能过审。
