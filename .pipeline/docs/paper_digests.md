## 汇总：三条线合起来告诉我们什么

### 1. 与最近邻的区分点在检测端，不在注入端

注入机制无法把 CoTGuard 与 BadChain 分开——两者都是黑盒 prompt 层往 CoT 塞东西。但**认识论地位不同**：

> BadChain 明确假设"后门触发器对防御方未知"，并据此论证检测不可行。
> CoTGuard 是**持钥验证方**，触发器已知。

这把问题从"未知触发器检测"转成**带密钥的假设检验**——而后者正是能承载定理的形式。这是全项目最重要的
一句话，应当写进 Introduction 的贡献段。

与另外两篇的边界更清楚：ShadowCoT 是白盒（attention 头定位 + 残差流扰动 + 对抗微调，0.15% 参数），
BadThink 需要微调投毒（供应链威胁模型），CoTGuard 零训练访问。但 **BadThink 的 trigger 形式与 `T(k,t)`
高度重叠**（同样是保持最终答案不变的风格化自然语言指令），必须在 Related Work 主动交代。

三篇**均未报告任何 FPR 或统计保证**——这是子领域通病，补上 Type I 控制本身即构成贡献。

### 2. 多跳空白是真的，但要把话说准

- 攻击线：三篇论文中 "agent" 一词出现 **0 次**，ShadowCoT 的"传播"严格是单模型链内的。**空白确凿。**
- 但 **Prompt Infection 的 Fig. 4 已经画过 ASR 随 agent 数量的变化**，还观察到不做 importance-score
  操纵时感染在 K=3 轮后消失。**"无人研究多跳传播"这个说法会被这篇直接反驳。**

保住问题的三点差异：(a) 他们的 payload 是**显式自复制**的（每个 agent 被指令逐字复制 `[[[...]]]` 块），
被刻意设计成不衰减；CoTGuard 的 trigger 是**被动语义残留**。(b) 他们纵轴是二元攻击成功率，不是连续的
可检测性统计量。(c) 无理论衰减模型、无 FPR 校准判定规则，"在 FPR ≤ α 下能撑几跳"在其框架内无法回答。

**因此贡献必须表述为**：被动语义信号的**可检测性**跨串行中继的**衰减律**与 `n*(α)`，并在引言主动引用
其 Fig. 4 作为最近先例。

### 3. 理论有一条诚实可走的路：共形有效性，而非密码学保证

水印文献的 Type I 控制全部源自**密钥与采样过程的密码学耦合**（verifier 可重算 `ζ_t`，需 token 级白盒
访问）。CoTGuard 是黑盒 + 语义相似度，拿不到 `Y_t ~ U(0,1)` 这种免费精确零分布。**强行声称有，一眼可辨。**

诚实替代是**共形校准**：用未注入 trigger 的干净轨迹校准集算经验 p 值

```
p_t = ( 1 + #{ j : s_j^clean ≥ s_t } ) / ( m + 1 )
```

在**可交换性**下给出有限样本 Type I 控制。地基从密码学换成可交换性，对黑盒设定可辩护。

拿到逐步 p 值后，**Tr-GoF 的算法第 5–6 步只吃 p 值序列**，整套 GoF 机器可直接搬来，与水印再无关系。

### 4. 现有检测器被证明次优——这是硬伤也是机会

Tr-GoF 证明：最优可检测区域边界是 `q + 2p = 1`，而 **sum-based 规则最好只能到 `q + p = 1/2`**。
**CoTGuard 的 Algorithm 4（逐步求和相似度）正属此族。** 这既解释了预印本 Table 4 中 anti-CoT 改写
伤害最大的现象，也把"换聚合方式"从工程调参升级为**有理论依据的必要改动**。

### 5. 可监控性叙事：能当引子，不能当主张

两者威胁模型正好相反——可监控性中**模型是对手**、监控方善意；CoTGuard 中**模型善意**、第三方复用者是
对手。懂 Korbak/Baker 这条线的审稿人会指出这是两个问题。

安全用法：(a) 借机器——FPR ≤ 1% 校准范式、7 级混淆压力分类法当攻击模型、judge-model 因子覆盖度当更
细粒度的衰减度量；(b) 只主张共享前提——推理链中的语义内容会延续到可观测文本，CoTGuard 是被动观测的
**主动探针补集**；(c) **不要**宣称版权检测是可监控性的一个实例，也不要把 LDR 改名成 monitorability score。

### 6. 最强自适应攻击已经具体化

**Guard-Lexicon + Do-Not-Mention + Monitor-Aware 三者叠加（压力等级 P ≥ 5），施加在中间 agent 上，
针对 external CoT。** 比 Table 4 的泛泛改写强得多：Guard-Lexicon 是**针对相似度检测器的定向词汇规避**，
而我们的 trigger 恰好活在 external CoT——经验上最脆弱的通道（Claude 上条件混淆成功率 75–90%，
而 internal CoT 仅约 25%）。

附赠两个实验设计红利：P=0..7 的压力分级可做**"混淆压力 × 跳数"二维鲁棒性网格**；且混淆压力本身要付出
32–45pp 的任务成功率代价，可画**检测率 vs 攻击者效用**曲线。
